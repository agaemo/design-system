Typography

フォントファミリー・サイズ・ウェイト・行間・字間のトークンをまとめたもの。これにより「本文は 16px、見出しは 24px で太字」のようなルールを変数として持ち、プロジェクト全体でブレなく使える。
サイズや行間は相互に連動しており、バラバラに使うのではなく用途に応じた組み合わせを選ぶこと（下の対応表参照）。

フォントファミリー: 現在はシステムフォント（font-sans / --font-family-sans）。日本語プロジェクトでは tokens/typography.json の fontFamily.sans を "Noto Sans JP" に変更し bun run build を実行する。等幅フォントは font-mono / --font-family-mono。
