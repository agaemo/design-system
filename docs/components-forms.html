Forms

Input / Textarea / Select / Checkbox / Toggle。フォームコントロールはすべて form-group でラップし、ラベル・ヘルパー・エラーをセットで扱う。

React では class → className、for → htmlFor に読み替える。

Input

1行のテキスト入力。form-group でラベル・入力・ヘルパーをまとめる。

通常

ログインに使用します 
<div class="form-group">
  <label class="form-label" for="email">
    メールアドレス<span class="form-required">*</span>
  </label>
  <input class="form-input" id="email" type="email" placeholder="you@example.com">
  <span class="form-helper">ログインに使用します</span>
</div>

エラー状態

使用できない文字が含まれています 
<!-- エラー時: input に is-error クラスを追加 + form-error を表示 -->
<div class="form-group">
  <label class="form-label" for="username">ユーザー名</label>
  <input class="form-input is-error" id="username" type="text" value="invalid user">
  <span class="form-error">使用できない文字が含まれています</span>
</div>

無効

変更するにはサポートへお問い合わせください 
<div class="form-group">
  <label class="form-label" for="email">登録メール</label>
  <input class="form-input" id="email" type="text" value="registered@example.com" disabled>
  <span class="form-helper">変更するにはサポートへお問い合わせください</span>
</div>

Textarea

複数行テキスト入力。Input と同じクラス体系を使い、一貫した見た目を保つ。

基本

最大 500 文字 
<div class="form-group">
  <label class="form-label" for="comment">コメント</label>
  <textarea class="form-textarea" id="comment" placeholder="内容を入力してください..."></textarea>
  <span class="form-helper">最大 500 文字</span>
</div>

Select

選択肢が 5〜7 個以内の場合に使う。それ以上はコンボボックス（検索付きドロップダウン）を検討する。

基本

<div class="form-group">
  <label class="form-label" for="lang">言語</label>
  <select class="form-select" id="lang">
    <option value="">選択してください</option>
    <option value="ja">日本語</option>
    <option value="en">English</option>
  </select>
</div>

Checkbox

複数選択・同意確認に使う。チェック色は accent-color でデザイントークンの accent に統一される。

基本（ヒントテキスト付き）

<label class="checkbox-wrap">
  <input type="checkbox" class="checkbox-input" checked>
  <div class="checkbox-text">
    <span class="checkbox-label">利用規約に同意する</span>
    <span class="checkbox-hint">続行するには同意が必要です</span>  <!-- 省略可 -->
  </div>
</label>

無効

<!-- disabled 時は label にも opacity を適用する -->
<label class="checkbox-wrap" style="opacity:0.45;cursor:not-allowed">
  <input type="checkbox" class="checkbox-input" disabled>
  <div class="checkbox-text">
    <span class="checkbox-label">変更不可の設定</span>
  </div>
</label>

disabled 時の opacity と cursor は CSS クラス化しておくと管理しやすい（例: .checkbox-wrap.is-disabled）。

Toggle / Switch

即時に反映される設定のオン/オフに使う。Checkbox との違いは即時性——確認ダイアログが不要な操作に向く。

ON 状態

<!-- ON: toggle-track に .on を追加、OFF: .on を外す -->
<label class="toggle-wrap">
  <div class="toggle-track on">
    <div class="toggle-thumb"></div>
  </div>
  <span class="toggle-label">通知をオンにする</span>
</label>

OFF 状態

<label class="toggle-wrap">
  <div class="toggle-track">  <!-- .on なし = OFF -->
    <div class="toggle-thumb"></div>
  </div>
  <span class="toggle-label">ダークモード</span>
</label>

React での実装例:

// const [on, setOn] = useState(false)
<label className="toggle-wrap" onClick={() => setOn(!on)}>
  <div className={`toggle-track ${on ? 'on' : ''}`}>
    <div className="toggle-thumb" />
  </div>
  <span className="toggle-label">通知をオンにする</span>
</label>
