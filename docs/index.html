セットアップ

このデザインシステムはローカルで動かすビルドツール。トークンを編集してビルドすると css/variables.css が生成される。その CSS ファイルをプロジェクトにコピーして使う。サーバー公開は不要。

1
ビルドして CSS を生成する
トークンを変更するたびに実行する。css/variables.css が更新される。
# design-system ディレクトリで実行
bun run build
2
生成した CSS をプロジェクトにコピーする
プロジェクトの src/styles/ など適切な場所にコピーする。ファイル名は任意。
# cp でコピー（1回ごとに手動でもよい）
cp css/variables.css ../my-project/src/styles/design-tokens.css

# または watch + cp でトークン変更を自動反映することもできる
3
プロジェクトで読み込む
/* globals.css などの先頭で import */
@import './design-tokens.css';

/* または HTML の <head> に <link> */
<link rel="stylesheet" href="./src/styles/design-tokens.css">
以降は var(--accent) var(--text-primary) 等を直接使う。
/* globals.css などで CSS を読み込む */
@import './design-tokens.css';
// tailwind.config.js — design-system の Tailwind 設定をコピーして使うか、
// design-system が同じ場所にある場合はパス参照でもよい
const base = require('../design-system/tailwind/tailwind.config')
module.exports = {
  ...base,
  content: ['./src/**/*.{html,js,jsx,ts,tsx}'],
}
4
トークンを使って実装する
ボタンを例に:
.button {
  background:    var(--accent);
  color:         var(--text-inverse);
  border-radius: var(--radius-md);
  padding:       var(--space-2) var(--space-4);
  font-size:     var(--font-size-sm);
  font-weight:   var(--font-weight-medium);
}
.button:hover { background: var(--accent-hover); }
<button class="bg-accent text-foreground-inverse rounded-md
         px-4 py-2 text-sm font-medium hover:bg-accent-hover">
  送信
</button>
