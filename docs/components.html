Actions

Button / Badge / Spinner / Tooltip。プレビューの直下にそれを生成する HTML を示す。

React では class → className、for → htmlFor に読み替える。

Button

アクションを起こすための要素。重要度に応じてバリアントを使い分ける。Primary は画面内に 1 つが原則。

バリアント

<button class="btn btn-primary">送信</button>
<button class="btn btn-outline">キャンセル</button>
<button class="btn btn-ghost">詳細</button>
<button class="btn btn-danger">削除</button>

サイズ

<button class="btn btn-primary btn-sm">Small</button>
<button class="btn btn-primary">Medium</button>
<button class="btn btn-primary btn-lg">Large</button>

無効 / ローディング

<!-- 無効 -->
<button class="btn btn-primary" disabled>Disabled</button>

<!-- ローディング: disabled + spinner を組み合わせる -->
<!-- spinner の border 色は白系に変える（背景が濃いため） -->
<button class="btn btn-primary" disabled>
  <span class="spinner spinner-sm"
        style="border-color:rgba(255,255,255,.3);border-top-color:white"></span>
  保存中...
</button>

Spinner の色 override だけは inline style を使う。CSS クラスにしてもよいが、使う場所が limited のため。

リンクとして使う

次のページへ 戻る 
<!-- <a> タグに同じクラスを付けるだけ -->
<a href="/next" class="btn btn-primary">次のページへ</a>
<a href="/back" class="btn btn-outline">戻る</a>

Badge

ステータス・カテゴリを示す小さなラベル。テキストだけでは状態が伝わりにくいときに補助として使う。

バリアント

Draft New 公開中 レビュー待ち エラー 情報 
<span class="badge badge-neutral">Draft</span>
<span class="badge badge-accent">New</span>
<span class="badge badge-success">公開中</span>
<span class="badge badge-warning">レビュー待ち</span>
<span class="badge badge-error">エラー</span>
<span class="badge badge-info">情報</span>

テキストと組み合わせる

山田 太郎 管理者
タスク名 期限超過 
<!-- インラインで並べる場合は flex コンテナで囲む -->
<div style="display:flex;align-items:center;gap:8px">
  <span>山田 太郎</span>
  <span class="badge badge-accent">管理者</span>
</div>
<div style="display:flex;align-items:center;gap:8px">
  <span>タスク名</span>
  <span class="badge badge-warning">期限超過</span>
</div>

Spinner

処理中の待機状態を示す。所要時間が不明な非同期処理に使う。

サイズ

<!-- spinner-sm (14px) / spinner-md (20px) / spinner-lg (32px) -->
<span class="spinner spinner-sm"></span>
<span class="spinner spinner-md"></span>
<span class="spinner spinner-lg"></span>

ページ全体のローディング

読み込み中... 
<div class="loading-screen">  <!-- flex + center のレイアウトクラスを用意する -->
  <span class="spinner spinner-lg"></span>
  <span>読み込み中...</span>
</div>

Tooltip

ホバーで補足情報を表示する。ラベルのないアイコンボタンや略語の説明に使う。長文・操作が必要なコンテンツには使わない。

基本

これがツールチップです ヘルプテキスト 
<!-- tooltip-wrap で囲むだけ。ホバーで tooltip-bubble が表示される -->
<span class="tooltip-wrap">
  <button class="btn btn-outline">ホバーで確認</button>
  <span class="tooltip-bubble">これがツールチップです</span>
</span>

<!-- アイコンボタンのラベル代わり -->
<span class="tooltip-wrap">
  <button class="btn btn-ghost btn-sm">?</button>
  <span class="tooltip-bubble">ヘルプテキスト</span>
</span>
