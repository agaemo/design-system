Layout & Content

Card / Alert / Table / Tabs / Avatar / Divider。画面の構造やコンテンツ表示に使うコンポーネント。

React では class → className に読み替える。

Card

関連するコンテンツをまとめるコンテナ。ヘッダー・フッターは省略できる。

ヘッダー・ボディ・フッター

プロジェクト設定

基本情報を変更します

プロジェクト名・説明・公開設定などを編集できます。 
<div class="card">
  <div class="card-header">
    <p class="card-title">プロジェクト設定</p>
    <p class="card-subtitle">基本情報を変更します</p>  <!-- 省略可 -->
  </div>
  <div class="card-body">
    コンテンツ
  </div>
  <div class="card-footer">  <!-- 省略可 -->
    <button class="btn btn-primary btn-sm">保存</button>
    <button class="btn btn-ghost btn-sm">キャンセル</button>
  </div>
</div>

ボディのみ（シンプル）

ヘッダー・フッターなしのシンプルなカード。 
<div class="card">
  <div class="card-body">
    コンテンツ
  </div>
</div>

Alert

ユーザーへの通知・フィードバック。処理結果・警告・エラーなど重要度に応じたバリアントを選ぶ。

Success

✓
保存しました
変更が正常に保存されました。
<div class="alert alert-success">
  <span class="alert-icon">✓</span>
  <div class="alert-body">
    <div class="alert-title">保存しました</div>  <!-- タイトルは省略可 -->
    <div>変更が正常に保存されました。</div>
  </div>
</div>

Warning / Error / Info

⚠
この操作は元に戻せません。
✕
メールアドレスが無効です。
ℹ
システムメンテナンスを予定しています。
<div class="alert alert-warning">
  <span class="alert-icon">⚠</span>
  <div class="alert-body">この操作は元に戻せません。</div>
</div>
<div class="alert alert-error">
  <span class="alert-icon">✕</span>
  <div class="alert-body">メールアドレスが無効です。</div>
</div>
<div class="alert alert-info">
  <span class="alert-icon">ℹ</span>
  <div class="alert-body">システムメンテナンスを予定しています。</div>
</div>

Tabs

同一画面内の関連コンテンツをグループ分けする。ページ遷移ではなくコンテンツ切り替えに使う。

基本（クリックで切り替わります）

概要のコンテンツがここに入ります。
設定のコンテンツがここに入ります。
履歴のコンテンツがここに入ります。
<!-- アクティブなタブに .active を付ける -->
<div class="tab-list-ui">
  <button class="tab-item-ui active">概要</button>
  <button class="tab-item-ui">設定</button>
  <button class="tab-item-ui">履歴</button>
</div>

<!-- パネルは hidden 属性で表示/非表示を切り替える -->
<div id="panel-overview">概要のコンテンツ</div>
<div id="panel-settings" hidden>設定のコンテンツ</div>
<div id="panel-history"  hidden>履歴のコンテンツ</div>

Modal

ボタン実行後などに表示するダイアログ。情報・警告・確認（破壊的操作）の3バリアント。
.modal-backdrop をクリックすると閉じる。スクロールロック・フォーカストラップは実装側で対応する。

フォーム入力（作成・編集）

<button class="btn btn-primary" onclick="openModal('modal-form')">プロジェクトを作成</button>

<div class="modal-backdrop" id="modal-form" hidden
     onclick="if(event.target===this)closeModal('modal-form')">
  <div class="modal">
    <div class="modal-header">
      <span class="modal-title">プロジェクトを作成</span>
      <button class="modal-close" onclick="closeModal('modal-form')">✕</button>
    </div>
    <div class="modal-body" style="display:flex;flex-direction:column;gap:16px">
      <div class="form-group">
        <label class="form-label" for="name">プロジェクト名<span class="form-required">*</span></label>
        <input class="form-input" id="name" type="text" placeholder="例: マーケティングサイト">
      </div>
      <div class="form-group">
        <label class="form-label" for="type">種別</label>
        <select class="form-select" id="type">
          <option value="">選択してください</option>
          <option value="web">Webアプリ</option>
          <option value="mobile">モバイルアプリ</option>
          <option value="other">その他</option>
        </select>
      </div>
      <div class="form-group">
        <label class="form-label" for="desc">説明</label>
        <textarea class="form-textarea" id="desc" placeholder="プロジェクトの概要を入力..."></textarea>
      </div>
    </div>
    <div class="modal-footer">
      <button class="btn btn-ghost" onclick="closeModal('modal-form')">キャンセル</button>
      <button class="btn btn-primary">作成する</button>
    </div>
  </div>
</div>

modal-body に flex-direction:column;gap:16px を指定してフォーム要素を縦並びにする。ネイティブ <select> はブラウザが枠外に描画するので overflow-y との競合なし。

情報（Info）— 処理完了・お知らせ

<!-- トリガー -->
<button class="btn btn-primary" onclick="openModal('modal-info')">情報モーダルを開く</button>

<!-- モーダル本体: hidden で非表示、backdrop クリックで閉じる -->
<div class="modal-backdrop" id="modal-info" hidden
     onclick="if(event.target===this)closeModal('modal-info')">
  <div class="modal">
    <div class="modal-header">
      <span class="modal-title">送信が完了しました</span>
      <button class="modal-close" onclick="closeModal('modal-info')">✕</button>
    </div>
    <div class="modal-body">
      フォームの内容が正常に送信されました。確認メールをお送りしましたのでご確認ください。
    </div>
    <div class="modal-footer">
      <button class="btn btn-primary" onclick="closeModal('modal-info')">閉じる</button>
    </div>
  </div>
</div>

警告（Warning）— 続行前に確認が必要

<button class="btn btn-outline" onclick="openModal('modal-warning')">警告モーダルを開く</button>

<div class="modal-backdrop" id="modal-warning" hidden
     onclick="if(event.target===this)closeModal('modal-warning')">
  <div class="modal modal-warning">  <!-- .modal-warning で上部ボーダーが黄色 -->
    <div class="modal-header">
      <span class="modal-title">⚠ 変更が保存されていません</span>
      <button class="modal-close" onclick="closeModal('modal-warning')">✕</button>
    </div>
    <div class="modal-body">
      ページを離れると編集中の内容が失われます。このまま続行しますか？
    </div>
    <div class="modal-footer">
      <button class="btn btn-ghost" onclick="closeModal('modal-warning')">編集に戻る</button>
      <button class="btn btn-primary">続行</button>
    </div>
  </div>
</div>

確認（Danger）— 取り消せない破壊的操作

<button class="btn btn-danger" onclick="openModal('modal-danger')">削除する</button>

<div class="modal-backdrop" id="modal-danger" hidden
     onclick="if(event.target===this)closeModal('modal-danger')">
  <div class="modal modal-sm modal-danger">  <!-- .modal-danger で上部ボーダーが赤 -->
    <div class="modal-header">
      <span class="modal-title">プロジェクトを削除しますか？</span>
      <button class="modal-close" onclick="closeModal('modal-danger')">✕</button>
    </div>
    <div class="modal-body">
      この操作は元に戻せません。プロジェクト内のすべてのデータが削除されます。
    </div>
    <div class="modal-footer">
      <button class="btn btn-ghost" onclick="closeModal('modal-danger')">キャンセル</button>
      <button class="btn btn-danger">削除する</button>
    </div>
  </div>
</div>
プロジェクトを作成
送信が完了しました
フォームの内容が正常に送信されました。確認メールをお送りしましたのでご確認ください。
⚠ 変更が保存されていません
ページを離れると編集中の内容が失われます。このまま続行しますか？
プロジェクトを削除しますか？
この操作は元に戻せません。プロジェクト内のすべてのデータが削除されます。

Divider

セクションを視覚的に区切る。ラベル付きは「または」のように選択肢を分けるときに使う。

ラベルなし

<hr class="divider-line">

ラベル付き

または
<div class="divider">または</div>
