Semantic Colors

「何に使うか」を名前にしたカラートークン。ページ背景には --bg-base、本文テキストには --text-primary のように、用途が名前から読める。
コンポーネントに #3b82f6 のような HEX 値を直接書くのではなく、このトークンを参照することで、デザインを変更するときも tokens/color/semantic.json を編集して bun run build するだけで全体に反映される。

コードでは必ずセマンティックトークンを使う。プリミティブカラー（--color-blue-500 等）をコードに直接書いてはいけない。

Primitive Colors

色を階調（グラデーション）で網羅したカラーパレット。neutral-50（ほぼ白）〜 neutral-950（ほぼ黒）のように、数値が大きいほど暗い。
Semantic Colors の参照元であり、プロジェクトのコードからは直接使わない。「このブランドカラーを変えたい」というときだけ、このファイルを触る。

アプリのコードでは使わない。セマンティックトークンを定義するときだけ参照する（tokens/color/semantic.json）。
ブランドカラーを変えるときは tokens/color/primitive.json を編集して bun run build を実行する。neutral / blue の2系統のみ定義し、他色はステータス用（green / yellow / red）。
